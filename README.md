# 🎥 Бот «Кружки» — лента видеосообщений с подписками и оплатой

Телеграм-бот: пользователи присылают кружки (видеосообщения) на модерацию,
принятые попадают в ленту. Доступ к ленте — по схеме
**подписка → 10 бесплатных → подписка на спонсоров → +10 → платные пакеты**.

Стек: Python 3.11+, aiogram 3, SQLite (aiosqlite), без внешних сервисов.

---

## Как работает схема

```
/start
  │
  ├─ не подписан на новостной канал ─► кнопка «Подписаться» + «Проверить»
  │
  ├─ подписан, есть просмотры ──────► лента (каждый показ −1 просмотр)
  │
  └─ 5 бесплатных закончились ──────► пакет 5 просмотров за 20 ⭐
```

**Просмотр списывается до отправки кружка** и возвращается, если файл не ушёл —
перезапуск бота и кнопка «Назад» бесплатных показов не дают. Все счётчики живут
в SQLite на сервере, клиент на них не влияет.

## Что нужно сделать в Telegram (по шагам)

1. **Создать бота** у [@BotFather](https://t.me/BotFather) → токен в `BOT_TOKEN`.
2. **Узнать свой id** у [@userinfobot](https://t.me/userinfobot) → `ADMIN_IDS`.
3. **Создать канал** и добавить бота **администратором** → `MAIN_CHANNEL_ID`
   (вида `-1001234567890`) и `MAIN_CHANNEL_URL`.
4. **Каналы-спонсоры**: в каждый добавить бота **администратором**, затем
   перечислить в `SPONSORS`:

   ```
   SPONSORS=-1001111111111|https://t.me/sponsor_one|Канал №1,-1002222222222|https://t.me/sponsor_two|Канал №2
   ```

5. *(необязательно)* **Приватный канал-хранилище** → `STORAGE_CHANNEL_ID`.
   Туда копируются принятые кружки как архив.

> ⚠️ **Главное ограничение Telegram:** проверить подписку можно только в канале,
> где бот — администратор. Если бот не админ, `getChatMember` вернёт ошибку,
> и бот посчитает пользователя неподписанным. При старте `run.py` сам проверяет
> права во всех каналах и пишет предупреждения в лог.

## Оплата

| Режим | Что настроить | Особенности |
|---|---|---|
| `PAYMENT_MODE=stars` (по умолчанию) | `PAY_PACK_STARS` | Telegram Stars (XTR). Не нужны ИП, договор и эквайринг. |
| `PAYMENT_MODE=provider` | `PROVIDER_TOKEN`, `PAY_PACK_RUB` | Рубли через ЮKassa/PayMaster. Нужен магазин у провайдера, подключённый к боту через @BotFather. |

Просмотры начисляются **только** в `successful_payment` и **один раз** на
`telegram_payment_charge_id` (уникальный индекс в таблице `payments`), поэтому
повторные вебхуки и повторные нажатия «Оплатить» баланс не удваивают.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/start` | все | регистрация, проверка подписки, меню |
| `/menu` | все | показать инлайн-меню |
| `/stats` | админ | статистика: юзеры, лента, просмотры, оплаты |
| `/pending` | админ | сколько кружков ждёт модерации |
| `/give <id> <views>` | админ | вручную начислить просмотры |
| `/ban` / `/unban <id>` | админ | блокировка доступа |
| `/admin` | админ | список админ-команд |

Модерация: пользователь присылает кружок → админам приходит кружок с кнопками
**✅ Принять / ❌ Отклонить**. Принятый попадает в ленту, автор получает
уведомление.

## Настройки в `.env`

| Переменная | По умолчанию | Описание |
|---|---|---|
| `FREE_VIEWS` | `5` | бесплатных просмотров при первом входе |
| `BONUS_VIEWS` | `0` | бонус за подписку на спонсоров (`0` = отключён) |
| `PAY_PACK_SIZE` | `5` | размер платного пакета |
| `PAY_PACK_STARS` | `20` | цена пакета в звёздах |
| `PAY_PACK_RUB` | `50` | цена пакета в рублях (режим `provider`) |
| `FEED_INCLUDE_OWN` | `0` | `1` — показывать автору его же кружки |
| `DB_PATH` | `data/bot.db` | путь к файлу базы |

Цены в звёздах и рублях не связаны: 50 ₽ ≈ 35 ⭐ по курсу Telegram.
Меняй `PAY_PACK_STARS`, чтобы получать нужную сумму в рублях.

## Второй аккаунт (userbot, MTProto)

Нужен, если хочешь импортировать кружки из каналов, где бот не состоит, или
публиковать от лица аккаунта, а не бота.

### 1. Получить api_id и api_hash

1. Открой <https://my.telegram.org>, войди номером **второго аккаунта**.
2. **API development tools** → **Create new application**.
3. Заполни App title и Short name, нажми **Create application**.
4. Скопируй **App api_id** и **App api_hash**.

`api_hash` — секрет: Telegram не даст его просто отозвать.

### 2. Заполнить `.env`

```dotenv
TG_API_ID=123456
TG_API_HASH=0123456789abcdef0123456789abcdef
TG_PHONE=+79991234567
TG_SESSION=data/userbot.session
```

Никому не пересылай эти значения. Файл `.env` и `*.session` в `.gitignore`.

### 3. Войти (один раз)

```powershell
.\.venv\Scripts\python.exe run_userbot.py login
```

Telegram пришлёт код — введи его в терминале. Если включена 2FA, введи пароль.
После этого создаётся `data/userbot.session`, и код больше не понадобится.

### 4. Проверить

```powershell
.\.venv\Scripts\python.exe run_userbot.py status
```

### Куда скидывать кружки

- **По одному** — боту в личку: попадает на модерацию, после принятия в ленту.
- **Пачкой** — папка `inbox/` в корне проекта: файлы из неё заливаются в ленту.

## Что делать тебе (2 действия)

1. В Telegram: @BotFather → `/newbot` → скопируй токен.
   @userinfobot → пришлёт твой ID.
2. Двойной клик по **`start.bat`** → вставь токен, ID, ID и ссылку канала.

Всё остальное бот сделает сам.

### Как кружки попадают в ленту (без второго аккаунта)

- **Способ 1:** присылаешь кружок боту в личку → он на проверке → принял → в ленте.
- **Способ 2:** создаёшь канал, добавляешь бота **админом**, вписываешь его ID
  в `.env` как `SOURCE_CHANNEL_ID` → **всё, что кидаешь в канал, автоматически
  появляется в ленте**. Публиковать от своего имени тоже можно в этом канале.
- **Способ 3:** кидаешь видеофайлы в папку `inbox` → `tools\import_inbox.py`.

## Деплой на Railway (бесплатно, бот не зависит от твоего компа)

Бот будет работать на сервере 24/7 — компьютер можно выключать.
Railway: **карта не нужна**, дают **$5 кредитов на 30 дней**, потом **бесплатный план**.

### Шаг 1. Подготовить проект (1 команда)

```powershell
.\.venv\Scripts\python.exe tools\prepare_deploy.py
```

Скрипт сам создаст git-репозиторий и проверит, что `.env` в него не попал.

### Шаг 2. Залить на GitHub

1. Открой <https://github.com/new>
2. Имя репозитория: `kruzhki-bot`, **не** ставь галочки README/gitignore
3. Нажми **Create repository**
4. GitHub покажет две команды — скопируй и выполни их в папке проекта:

```powershell
git remote add origin https://github.com/ТВОЙ_НИК/kruzhki-bot.git
git push -u origin main
```

### Шаг 3. Задеплоить на Railway

1. <https://railway.com> → **Login with GitHub** (карта не нужна)
2. **New Project** → **Deploy from GitHub repo** → выбери `kruzhki-bot`
3. Railway сам соберёт Python-проект (конфиг уже в `railway.json`)

### Шаг 4. Вставить переменные

В `.env` лежат твои секреты — на Railway их надо вставить **отдельно**:

```powershell
.\.venv\Scripts\python.exe tools\env_for_railway.py
```

Скрипт выведет готовый список. Скопируй его целиком и вставь на Railway:
**Свой сервис** → **Variables** → **Raw Editor** → вставить → **Update**.
После этого Railway сам перезапустит бота.

### Шаг 5. Сохранить базу данных

**Пользователи, просмотры и балансы живут в SQLite.** Без отдельного диска они
стираются при каждом обновлении.

1. **+ New** → **Volume**
2. Подключи его к сервису бота
3. **Mount path**: `/data`

Это учтено: переменные `DATA_DIR=/data` и `DB_PATH=bot.db` уже в списке из шага 4.

### Шаг 6. Проверить

Railway → **Deployments** → **View Logs**. Должно быть:

```
Бот запущен: @krughbot
✅ новостной канал: права админа есть
✅ канал с кружками: права админа есть
Start polling
```

Напиши боту `/start` — должен ответить.

### Важно знать про бесплатность

| Период | Что происходит |
|---|---|
| Первые 30 дней | $5 кредитов — бот работает 24/7 |
| Потом | Бесплатный план: бот **засыпает** при простое, просыпается от сообщения |
| Нюанс | Пока бот «спит», он не отвечает первым; первое сообщение его разбудит |

Если нужен **непрерывный** 24/7 без засыпания — самый дешёвый вариант это
**Oracle Cloud Free Tier** (бесплатно навсегда, но просит карту для проверки).

вырастет кратно — меняется только слой `bot/db.py`.

## Частые вопросы

**Можно ли обойти подписку?** Нет: проверка идёт через Telegram API на сервере.
Если человек отписался после проверки, доступ закроется при следующей проверке
(на каждом `/start` и каждом действии с лентой).

**Нужно ли перезаливать кружки?** Нет. Хранится `file_id`, по нему Telegram
отдаёт тот же файл сколько угодно раз.

**Что если кружок удалят из Telegram?** `send_video_note` вернёт ошибку, бот
вернёт списанный просмотр и предложит другой кружок.

**Несколько админов?** `ADMIN_IDS=111,222` — кружок на модерацию придёт всем.
